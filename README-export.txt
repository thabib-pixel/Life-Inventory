Life Shelf v50.4 Deployment Package

Upload all root files plus the full images/ folder to GitHub or Netlify.

Required root files:
- index.html
- netlify.toml
- inventory-data.json
- backup-report.txt
- README-export.txt

Required folder:
- images/

Do not upload only the five root files without images/, or product photos will break.

After deployment:
1. Wait for Netlify to publish.
2. Open the deployed site in an incognito/private window.
3. Confirm the top-right label says Life Shelf v50.4.
4. Confirm no Import Backup, Reload Current Data, Restore v43, or Reload v43 buttons display.
5. Test Export Site ZIP.
6. Test Day Look Planner: add a product, save a look, move steps, and verify warnings/wait times.
